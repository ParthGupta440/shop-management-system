# Shop Management System

## Introduction
This project is a Shop Management System developed using Python. I made this project as part of my Python Essentials course. The main purpose of this project is to manage different activities of a shop such as customer management, product and stock management, sales, suppliers, billing, and payments.
This project helped me understand how different Python modules can work together in a real application. The project is menu-driven and allows the user to perform different operations through simple menu options.

## Objectives
* To manage customer information
* To maintain product and stock details
* To record sales transactions
* To generate bills and handle payments
* To manage supplier records
* To generate shop reports

## Features

### Customer Management
The user can add new customers, view customer records, and search for customers using their ID.

### Product Management
The system allows products to be added, viewed, and searched. Stock quantities can also be updated whenever products are purchased or sold.

### Sales Management
Sales can be created for existing customers and products. The system automatically updates stock after a sale is completed.

### Supplier Management
Supplier information can be stored, and stock can be increased when new products are purchased from suppliers.

### Payment Management
The project can generate bills, calculate GST, and store payment records.

### Report Generation
A simple report can be generated to view the total number of customers, products, suppliers, sales, and available stock.

## Technologies Used

## Project Files
* `main.py` – Main menu and program control
* `customer.py` – Customer operations
* `product.py` – Product and stock management
* `sales.py` – Sales operations
* `supplier.py` – Supplier management
* `payment.py` – Billing and payment operations

## How to Run
1. Install Python on your system.
2. Download all project files.
3. Open the project folder in VS Code or any Python IDE.
4. Run the `main.py` file.
5. Use the menu options displayed on the screen.
