# Shop Management System

## Problem Statement

In small shops and retail stores, managing customer records, product inventory, supplier information, sales transactions, and payments manually can be difficult and time-consuming. Traditional record-keeping methods often lead to errors, misplaced information, and difficulties in tracking stock availability and sales history.

As the number of customers and products increases, maintaining accurate records becomes more challenging. Shop owners need a simple and efficient system that can help them organize daily business operations and reduce manual effort.

To address this problem, a **Shop Management System** has been developed using Python. The system provides a menu-driven interface through which users can manage customers, products, suppliers, sales, billing, and payments. The project is designed to demonstrate the practical implementation of Python programming concepts while solving a real-world management problem.

---

## Project Description

The Shop Management System is a console-based Python application that helps users perform various shop-related operations through different modules.

The application allows users to:

* Store and manage customer information
* Maintain product and inventory records
* Record sales transactions
* Manage supplier details
* Generate bills and process payments
* View reports related to shop activities

The project follows a modular programming approach where different functionalities are separated into individual Python files. This improves code organization and makes the project easier to understand and maintain.

## Example Workflow

### Step 1: Add Customer

```text
Customer ID: C101
Name: Rahul Sharma
Phone: 9876543210
Email: rahul@gmail.com
Address: Bhopal
```

### Step 2: Add Product

```text
Product ID: P101
Product Name: Laptop
Category: Electronics
Price: 45000
Quantity: 10
```

### Step 3: Create Sale

```text
Customer ID: C101
Product ID: P101
Quantity: 2
```

Output:

```text
Sale completed successfully.
Total Amount: ₹90000
```

### Step 4: Generate Bill

```text
Subtotal: ₹90000
GST (5%): ₹4500
Total Bill: ₹94500
```

### Step 5: Make Payment

